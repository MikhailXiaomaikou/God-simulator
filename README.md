# 创世记 · God-simulator

God is the first vibecoder.

在黑暗的渊面上，你是神的灵。按住画面言说，每一句话成就一步。一开始是起初的七日：光、穹苍、旱地、日月星、鱼鸟、走兽与人，第七日不必再说话，静候便是安息。之后故事接着往下走，经过伊甸、该隐、洪水、巴别，再到亚伯拉罕、雅各与约瑟，一直走完整部创世记（1:1 — 50:26）。

## 运行

用浏览器直接打开 `index.html` 就能玩。不需要安装、构建或联网，所有画面和声音都在运行时生成。也可以部署到 GitHub Pages。

有声音，建议打开扬声器或戴上耳机。

## 操作

| 动作 | 作用 |
| --- | --- |
| 移动鼠标／手指（或方向键、WASD） | 引领神的灵 |
| 按住画面／空格／回车 | 言说：神谕逐字浮现，大地随之震颤；说满后松手，话语成就 |
| `L` 或「卷」 | 创世日志 |
| `P` 或「影」 | 留影，把当前世界存成图片 |
| `M` 或「声」 | 声音开关 |
| `F` | 全屏 |
| `H` 或 `?` | 说明 |

- 话语在神的灵所在之处成就。光从那里迸发，青草从那里蔓延，鱼、鸟、走兽和人也从那里出来。
- 说「又造众星」时，灵在天上划过的轨迹会成为你自己的星座，以后每一夜都会亮起。
- 进度自动保存，下次打开可以接着创世。

## 创世进程（卷一）

每一句话语在日志里都是一条命令，每一日结束时提交一次。之后的每一卷各开一条分支（`git checkout -b 伊甸`……）。

- **起初**（1:1–2）
  - `git init 天地`
- **第一日**（1:3–5）
  - `add 光`
  - `separate 光 暗`
  - `name 光 as 昼, 暗 as 夜`：「昼」由光聚成，「夜」由黑暗本身聚成
  - `commit -m "头一日"`：有晚上，有早晨
- **第二日**（1:6–8）
  - `add 穹苍 --between 水 水`：有了空气，天第一次变蓝
  - `name 穹苍 as 天`
  - `commit -m "第二日"`：这一日没有「神看着是好的」，忠于经文
- **第三日**（1:9–13）
  - `gather 水 && add 旱地`
  - `name 旱地 as 地, 水 as 海`
  - `grow 青草 菜蔬 --from 灵`
  - `grow 树木 --kind 各从其类`
  - `commit -m "第三日"`
- **第四日**（1:14–19）
  - `add 光体 --in 穹苍`：三日来没有光源的光凝成太阳
  - `assign 日 → 昼, 月 → 夜`
  - `for (星 of 众星) 摆列(星, 天空)`
  - `commit -m "第四日"`：第一个真正的夜晚
- **第五日**（1:20–23）
  - `spawn 鱼 大鱼 --count 多多`
  - `spawn 雀鸟 --in 天空`
  - `bless 鱼 鸟 --multiply`
  - `commit -m "第五日"`
- **第六日**（1:24–31）
  - `spawn 牲畜 昆虫 野兽 --kind 各从其类`
  - `create 人 --image 神 --as 男,女`：人由尘土而成，灵把自己的一部分光分给了他们
  - `bless 人 --fruitful --multiply`
  - `review --all  # ✓ 甚好`
  - `commit -m "第六日"`
- **第七日**（2:1–3）
  - `bless 第七日 --holy`：「圣」由万物各自的质料一同写成
  - `rest  # no diff`：不再言说，静止七息
  - `✓ build passed · 7 日 · 27 句话 · 0 个 bug`

## 全书终了之后

走完创世记之后，世界会一直自己运转下去：

- 日升月落，星辰转动，鲸在夜里歌唱，萤火在草间明灭。
- 鸟在黄昏归巢，人在树下歇息。
- 神的灵经过的地方，万物会显出自己的名字；按住画面，就能看到它被造时的经文。

## 技术

- 纯静态文件，使用经典 `<script>`，不依赖任何库，也没有图片或音频素材。字体是三种开源书法字体的子集，放在 `fonts/`，离线也能用。
- 天与海由 WebGL 着色器绘制，不支持 WebGL 时自动退回 Canvas2D。大地、草木和生灵用 Canvas2D 绘制，声音全部由 WebAudio 实时合成。
- 帧率偏低时自动降低画质。

```
index.html          舞台
css/style.css       文字与界面
js/core.js          数学、噪声、事件
js/world.js         世界的状态：创造的程度、昼夜之钟、大地的形状、光与色
js/story.js         卷一「七日」的剧本：二十八步，每步只成就它自己
js/book.js          全书：卷的登记、情节时间线、幕布与卷首
js/book/*.js        卷二至卷八：伊甸、该隐、洪水、巴别、亚伯拉罕、雅各、约瑟
js/cast.js          人物：亚当、夏娃……约瑟，以及天使、骆驼、驴、公羊
js/sky.js           天与海（WebGL）
js/land.js          大地与草木
js/sea.js           鱼与大鱼
js/air.js           飞鸟
js/beasts.js        牲畜、野兽、昆虫与人
js/fx.js            灵、光、名字、星座
js/audio.js         声音
js/ui.js            神谕、经文、七日之印、创世日志
js/main.js          输入、言说的仪式、黎明、安息、存档
```

调试用参数：

- `index.html?stage=N`：直接恢复到第 N 句话语成就之后。
- `&fast=K`：把故事节奏加快 K 倍。
- `&q=1`：锁定画质。
- 在控制台里可以用 `GS.debug.next()` 直接成就下一句。
